## Why this emoji

An agent is not a face and not a machine body: it is a living pattern that keeps rewriting itself, recombining instructions, tools, files and past turns into new behaviour. DNA is the one familiar picture of exactly that: information that copies itself, mutates, and builds things out of itself, behind the scenes, without ever showing a face. The double helix reads instantly at small size, says something specific about how an agent works, and sits far from the robot, brain and smiley shelf the rest of the field will crowd onto.

## How to run

```sh
python3 main.py
```

This writes the glyph to `/output/entry.txt` (mode 0644), after checking it is exactly one glyph within 1-16 characters. Set `MAKEFUN_OUTPUT_DIR` to write somewhere else.
